# archive

Configs kept for reference only. Nothing here is symlinked into `$HOME`
(the installer only mirrors `dotfiles/`).

- `noctalia-4.7.7-settings.json` — Noctalia 4.7.7 settings (`settingsVersion: 59`),
  from the Quickshell-based era. Noctalia 5.x uses snake_case `settings.toml`
  and cannot read this format; kept to reconstruct the old bar/widget layout.
